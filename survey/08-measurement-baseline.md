## 측정 방법 (2주 뒤)

### 유튜브 쪽

```bash
venv/bin/python3 - <<'PY'
# survey/baseline-2026-08-25.json 을 만든 것과 같은 스크립트를 다시 실행
PY
```

`subs_per_1k_views` 가 0.108 에서 얼마나 움직였는지 본다.

### 사이트 쪽 (GA4, G-0PNL94C6J7)

탐색 > 자유 형식에서:
- 측정기준 `세션 소스` / `세션 매체` / `세션 캠페인`
- 측정항목 `세션`, `참여 세션`, `이벤트 수`
- 필터 `세션 매체 = shorts`

확인할 것:
- `youtube / shorts / profile` 세션이 0 이상인가 (지금까지는 측정 불가였다)
- 그중 `calc_run` 이벤트가 발생했는가 (계산기를 실제로 썼는가)

`calc_run` 은 `ep.tool` 파라미터에 계산기 이름이 붙는다.

## 검증한 것 (2026-08-25)

- GA4 태그 `G-0PNL94C6J7` 계산기 페이지에 정상 삽입
- `gtag("config", ...)` 초기화 확인
- UTM 이 `dl` 파라미터로 전송되는 것 확인
- `calc_run` 이벤트가 `ep.tool=dividend-calculator` 와 함께 발화하는 것 확인
- 브라우저 자동화 환경에서 collect 응답이 503 이었으나, 같은 엔드포인트를
  서버에서 호출하면 204 다. 환경 아티팩트이고 실제 사용자에는 영향 없다

## 판정 기준

2주 뒤 다음 중 하나라도 참이면 프로필 링크가 작동한 것으로 본다.
