# SXO Gap Analysis — investiqs.net (평균 순위 26.1, 3개월 클릭 2회)

한계 고지: render_page.py 대신 WebFetch로 대상 페이지를 파싱했고(정확한 word count·raw HTML 스키마 검증은 아님), SERP는 WebSearch 결과(Google, 한국어)를 사용했다 — 실제 개인화/지역화된 Google SERP와는 순위가 다를 수 있다. Naver 노출 비중은 WebSearch 결과에 나타난 도메인만으로 추정한 것이며, 별도 Naver 검색 API 데이터는 없다.

## 한국 시장 특수성 체크

세 쿼리 모두 Google WebSearch 상위 결과에 **Naver 블로그·카페가 0건** 노출됐다. 즉 "Naver가 이 쿼리를 잠식해서 Google에서 못 이긴다"는 가설은 관측된 데이터상 근거가 약하다. 오히려 Google 자체에서 이미 은행/증권사/자산운용사/정부기관/대형 핀테크 미디어가 상위를 채우고 있어, **경쟁자가 도메인 신뢰도가 매우 높은 기관 브랜드라는 점이 진짜 장벽**이다.

## 결론: 26위 → 10위, 콘텐츠 개선만으로 가능한가?

**질의별로 다르다.**

1. **계산기 질의(연금저축 세액공제 계산기)**: 가능성 있음(조건부). 페이지 타입이 이미 정합하고, 실제 툴 경쟁자가 1개뿐이라 스키마 추가·UX 개선·소수 백링크만으로도 순위 이동 여지가 있다. 우선순위 1위로 개선 투자할 가치.

2. **두 개의 블로그형 질의(외국납부세액공제, 건강보험료)**: 콘텐츠 개선만으로는 한계가 크다. 문제는 콘텐츠 깊이가 아니라 (a) 저자가 "AI 보조 작성"으로만 표기되어 세금 YMYL 주제에서 전문가 신뢰 신호가 없고, (b) 상위 5개 결과 전부가 은행·자산운용사·세무법인·정부기관이라는 도메인 자체의 권위 격차, (c) 과거 896편 대량생성/239페이지 색인거부 이력에서 오는 도메인 전체 신뢰 잔재. 이는 **콘텐츠 문제라기보다 도메인 신뢰(E-E-A-T) + 시장 구조(경쟁자가 실제 금융기관) 문제**로 판단된다(추정). 콘텐츠 수정은 필요조건이지만 충분조건은 아니다 — 저자 신뢰 표기 개선(실명/자격 명시 또는 전문가 검수 명시), 도메인 권위 축적(백링크, 브랜드 검색), 색인 거부 이력 해소가 병행되어야 순위 이동이 현실적이다.
